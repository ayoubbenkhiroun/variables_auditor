Camunda FlowAudit Pro — Guide d'utilisation

Version 1.0 — Application web monopage (HTML/CSS/JS) — Stockage local IndexedDB

Camunda FlowAudit Pro est un outil destiné aux équipes de développement, d'architecture et de gouvernance. Il permet d'auditer les conventions de nommage des variables Camunda BPMN/FEEL, de valider la structure des appels de sous-processus, de contrôler la conformité du nommage BPMN, et de cartographier les activités d'un processus avec matricage de complétude.

Aucune donnée ne quitte votre navigateur. L'historique est stocké localement via IndexedDB.

1. Authentification

Champ Valeur par défaut
Identifiant pdacamunda ou user
Mot de passe pdacamunda

La connexion est locale (côté navigateur). Après validation, le tableau de bord principal s'affiche.

2. Navigation Générale

Barre latérale gauche

4 groupes de modules : Audit des Variables, Sous-processus, Nommage BPMN, Module PMG. Chaque groupe se déplie pour révéler les onglets.

En-tête supérieur

Titre de la page active, sélecteur de thème (Sombre, Deep Night, Clair, Cyberpunk), bouton "Charger démo", bouton "Réinitialiser".

Modules disponibles

  • Audit des Variables : Import, configuration, résultats, dashboard, graphe relationnel, classement, historique.
  • Sous-processus : Analyse des Call Activities, détection de boucles circulaires, cartographie.
  • Nommage BPMN : Audit des conventions de nommage des éléments BPMN (IDs, tâches, gateways, événements, messages, signaux).
  • Module PMG (Process Matrix Governance) : Cartographie des activités, matrice de gouvernance, glossaire des variables, documentation technique automatisée.

3. Module : Audit des Variables

3.1 Import des données

Formats supportés : .xlsx, .xls, .csv, .bpmn, .xml

Méthodes d'import :

  • Glisser-déposer un fichier dans la zone de dépôt
  • Cliquer sur la zone pour ouvrir le sélecteur de fichier
  • Saisie manuelle : Saisir une variable par ligne dans le champ de texte
  • Charger démo : Bouton dans l'en-tête pour charger 10 variables simulées

Après l'import d'un fichier Excel/CSV, la section de mappage apparaît pour associer les colonnes (Variable, Processus Parent, Processus Appelant). Un aperçu des données détectées s'affiche en temps réel.

3.2 Configuration des règles

L'onglet Configuration permet d'activer/désactiver chaque règle d'audit :

Règle Type
camelCase obligatoire Erreur
Pas d'espaces Erreur
Pas de caractères spéciaux Erreur
Ne commence pas par un chiffre Erreur
Pas d'accents Erreur
Mots réservés FEEL/BPMN Erreur
Longueur max 255 Erreur
Pas de snake_case Avertissement
Pas d'underscore en bordure Avertissement
Pas de double underscore Avertissement
Pas de tiret ou point Erreur
Nom non vide Erreur

Options complémentaires : Mots réservés personnalisés, niveaux de sensibilité, équipes propriétaires.

3.3 Analyse

Cliquez sur Analyser pour lancer l'audit. Une barre de progression s'affiche pendant l'analyse (3 secondes). Les onglets Résultats, Tableau de bord, Schéma Relations et Classement deviennent accessibles.

3.4 Résultats

Le tableau des résultats affiche pour chaque variable :

  • Nom original en police monospace
  • Statut : Conforme (vert), Attention (jaune), Non conforme (rouge)
  • Problèmes : Liste détaillée des violations
  • Suggestion : Proposition de correction en camelCase (éditable)
  • Sécurité & Tags : Sélecteurs de sensibilité et d'équipe propriétaire
  • Processus Parent / Appelant : Contexte extrait du fichier
  • Actions : Bouton Copier pour chaque suggestion

Filtres : Pills (Tous / Conformes / Non conformes / Avertissements), recherche plein texte, tri, pagination.

Actions globales : Appliquer toutes les suggestions, exporter CSV/Excel, télécharger le BPMN corrigé (si source BPMN).

3.5 Tableau de bord

KPIs : Score de conformité (%), Couverture de gouvernance (%), Longueur moyenne des noms.

Graphiques : Répartition des statuts (donut), Problèmes les plus fréquents (barres), Distribution par longueur de nom (courbe), Tendance historique du score, Gouvernance - Sensibilité (donut), Gouvernance - Répartition par équipe (barres).

Filtres : Par processus, équipe propriétaire, niveau de sensibilité.

3.6 Schéma des relations

Graphe interactif (Vis.js) montrant les liens entre processus et variables. Filtres par processus et par variable, option "Afficher uniquement les variables non conformes", mode plein écran.

3.7 Classement

Classement des variables par fréquence d'utilisation. Statistiques, top 10 graphique, recherche, tri, export CSV.

3.8 Historique

Chaque analyse est automatiquement sauvegardée dans IndexedDB. Ouvrir, supprimer, effacer tout, sauvegarder/importer l'historique complet (JSON).

4. Module : Sous-processus (Call Activities)

4.1 Import

Mêmes méthodes que le module Variables (Excel/CSV/BPMN, saisie manuelle). Format manuel : processus_parent;sous_processus (une relation par ligne).

4.2 Analyse d'impact

KPIs : Relations totales, processus parents uniques, sous-processus uniques, boucles circulaires détectées.

Détection de boucles circulaires : Algorithme DFS pour identifier les dépendances cycliques.

Tableau : Sous-processus, impact (nombre d'appels), parents appelants, statut/problèmes.

4.3 Cartographie

Graphe interactif (Vis.js) de l'arborescence des appels. Couleurs : Parent (bleu), Sous-processus (vert), Boucle circulaire (rouge). Filtres par parent/sous-processus, option "Afficher uniquement les boucles circulaires".

5. Module : Nommage BPMN

5.1 Import

Déposer un fichier .bpmn ou .xml. L'application liste les éléments détectés. Avant l'analyse, vous pouvez (dé)sélectionner les règles de nommage à appliquer.

5.2 Personnalisation des règles

Ajouter / Modifier / Supprimer des règles. Créer des règles basées sur des expressions régulières. Restaurer les valeurs par défaut.

5.3 Résultats

KPIs : Total éléments audités, conformité globale (%), erreurs critiques, avertissements.

Graphiques : Répartition des conformités (donut), violations par type d'élément (barres).

Tableau : Type, ID technique, libellé actuel, statut, conventions non respectées, suggestion corrective.

Export : Télécharger le BPMN corrigé, exporter CSV/Excel.

6. Module PMG (Process Matrix Governance)

6.1 Import BPMN

Déposer un fichier .bpmn ou .xml. L'application extrait les activités (User Tasks, Service Tasks, Call Activities, etc.) et affiche un résumé.

6.2 Informations techniques

Dans la page Matrice PMG, renseignez : nom du processus, ID technique, version, propriétaire métier, modélisateur, exécutable, description/objectif. Ces informations sont persistées en LocalStorage.

6.3 Matrice de gouvernance

Tableau listant chaque activité avec : type de composant, entité réalisatrice (Pool/Lane), inputs/outputs extraits du BPMN, champ "Applicable dans quel cas ?" (éditable), commentaire (éditable). Filtres et exports CSV/Excel/PDF.

6.4 Dashboard PMG

KPIs : Score de complétude, complexité globale, volume de données (I/O), total activités.

Diagnostics : Alertes automatiques (documentation incomplète, tâches sans Lane, tâches sans I/O, sous-processus sans paramètres, etc.).

Glossaire interactif : Variables extraites avec type de flux, producteurs, consommateurs, description éditable.

Guide technique : Document auto-généré (Markdown) contenant métadonnées, KPIs, matrice, glossaire. Copier, télécharger, imprimer/PDF.

  • Édition inline : Suggestions de correction éditables directement dans le tableau.

  • Sauvegarde automatique : Les modifications dans la matrice PMG sont persistées instantanément.

12. Foire aux questions (FAQ)

Q : Mes données sont-elles envoyées sur Internet ?

NON. L'application est 100 % client. Aucune donnée ne quitte votre poste.

Q : Comment changer le mot de passe par défaut ?

Ouvrez js/app.js, recherchez USER_CREDENTIALS et modifiez les valeurs.

Q : Puis-je importer un BPMN avec plusieurs processus ?

Oui. Tous les processus du fichier BPMN sont explorés et analysés.

Q : Quels navigateurs sont supportés ?

Chrome 90+, Firefox 90+, Edge 90+, Safari 15+.

Q : Comment effacer l'historique ?

Dans le Dashboard, section "Analyses sauvegardées", utilisez "Tout effacer".

Q : Puis-je réimporter une analyse sauvegardée ?

Oui. Cliquez sur "Charger" dans l'historique pour restaurer l'analyse dans le module Variables.
